# E-Commerce Sales Analytics Dashboard

## 📊 Project Overview

This project analyzes e-commerce sales data and presents the results through an interactive Microsoft Excel dashboard.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- PivotTables
- PivotCharts
- KPI Analysis
- Data Visualization

## 📌 Key KPIs

- Total Sales: 58,65,293.05
- Total Orders: 34,500
- Average Order Value: 170.01
- Returned Orders: 1,903

## 📈 Dashboard Analysis

The dashboard includes:

- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Payment Method-wise Sales Analysis
- Monthly Sales Trend
- Returned Orders Analysis
- Key Performance Indicators (KPIs)

## 🎯 Objective

The objective of this project is to analyze e-commerce sales data, identify important sales patterns, and present business insights using an easy-to-understand Excel dashboard.
